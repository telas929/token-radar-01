# Token Launch Radar

Autonomous Token Launch Radar built for make.fun's "Build the best token launch radar" competition ($1,325 USDC prize pool).

## Overview
- Scans pre-token protocols across the DeFi universe based on the frozen DefiLlama snapshot.
- Evaluates implied launch valuations using dynamic TVL multipliers, 7-day velocity, protocol age, and capital efficiency.
- Generates structured, high-signal airdrop farming roadmaps with actionable steps, risk scores, and expected reward windows.
- Powered by autonomous agentic pipeline under contributor `telas929`.
